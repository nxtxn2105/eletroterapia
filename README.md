# Eletroterapia Esportiva Visual

Landing page estática para o MVP do Guia Visual de Eletroterapia Esportiva.

## Estrutura

- `index.html`: conteúdo e estrutura da página.
- `styles.css`: identidade visual, responsividade e componentes.
- `script.js`: interações dos blocos expansíveis.

## Publicação na Vercel

Importe este repositório na Vercel como um projeto estático. Não é necessário comando de build: o arquivo `index.html` fica na raiz.

## Observações

O texto foi estruturado como material educacional e de apoio à consulta. Os parâmetros e aplicações devem ser validados por fisioterapeuta responsável, literatura específica, manual do fabricante e normas profissionais aplicáveis.
